# Cheatsheet

| Situation | Decide | Check |
|---|---|---|
| 需要高增益 | 选高输出阻抗/级联结构 | 摆幅、合规电压、极点 |
| 需要宽带 | 降低高阻节点阻抗或做补偿 | 噪声、功耗、相位裕度 |
| 需要低噪声 | 增大输入器件或优化偏置 | 1/f、热噪声、带宽 |
| 需要高匹配 | 对称、共心、dummy、充分面积 | 梯度、应力、寄生 |
| OCR 公式含糊 | 回看原 PDF 页面 | 不要猜负号、下标、幂次 |

**默认顺序**：拓扑 → 工作区/偏置 → 一阶指标 → 非理想因素 → 稳定性/噪声 → 版图与后仿真。
