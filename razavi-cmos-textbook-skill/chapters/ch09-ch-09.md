# 第 9 章：运算放大器

## 核心思想
运放设计把差动输入级、增益级、输出级和偏置组织成满足增益、摆幅、驱动、噪声和功耗的系统。

## 框架与模型
- **两级运放**：用它建立本章的第一层可计算模型。
  - 使用时机：规格分析、手算估算或需要快速定位主导因素时。
  - 方法：先写假设与边界，再逐步加入影响结果的非理想因素。
- **分层近似**：优先保留决定设计选择的项，随后用小信号、寄生和统计模型校正。

## 关键概念
- **两级运放**：本章中的关键分析维度。
- **folded cascode**：本章中的关键分析维度。
- **class A/AB**：本章中的关键分析维度。
- **输入共模范围**：本章中的关键分析维度。
- **输出摆幅**：本章中的关键分析维度。

## 设计规则
- Design from specifications backward: headroom and load set topology, then gain and speed set device sizing.
- 任何公式都必须和工作区、端电压、负载、带宽或工艺假设一起使用。
- 把增益、摆幅、噪声、速度和功耗视为耦合预算，不孤立优化单一指标。

## 反模式
- 直接套用长沟道或理想器件公式而不检查适用条件。
- 只看低频增益，忽略极点、寄生、稳定性和后仿真。
- 把 OCR 识别出的公式当作无误；上下标和负号必须回看原页。

## Worked Example
以一个规格驱动的手算为例：先选拓扑并写出假设，再计算一阶增益/电流，随后加入 ro、寄生或失配，最后以摆幅、带宽和功耗检查结果是否可实现。
