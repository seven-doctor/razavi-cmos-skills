# 第 1 章：学习路径与模拟设计方法

## 核心思想
建立模拟 CMOS 设计的分析语言：先用直观近似建立模型，再逐步加入非理想因素并量化误差。

## 框架与模型
- **近似层级**：用它建立本章的第一层可计算模型。
  - 使用时机：规格分析、手算估算或需要快速定位主导因素时。
  - 方法：先写假设与边界，再逐步加入影响结果的非理想因素。
- **分层近似**：优先保留决定设计选择的项，随后用小信号、寄生和统计模型校正。

## 关键概念
- **近似层级**：本章中的关键分析维度。
- **观察—分析—综合**：本章中的关键分析维度。
- **速度—精度—功耗折衷**：本章中的关键分析维度。

## 设计规则
- Use a simple model first, then add the smallest non-ideality that changes the design decision.
- 任何公式都必须和工作区、端电压、负载、带宽或工艺假设一起使用。
- 把增益、摆幅、噪声、速度和功耗视为耦合预算，不孤立优化单一指标。

## 反模式
- 直接套用长沟道或理想器件公式而不检查适用条件。
- 只看低频增益，忽略极点、寄生、稳定性和后仿真。
- 把 OCR 识别出的公式当作无误；上下标和负号必须回看原页。

## Worked Example
以一个规格驱动的手算为例：先选拓扑并写出假设，再计算一阶增益/电流，随后加入 ro、寄生或失配，最后以摆幅、带宽和功耗检查结果是否可实现。
